# Naming conventions

## Variables
- Use `snake_case` for variable names.
- Variable names should be descriptive and concise.

## Classes
- Use `PascalCase` for class names.
- Class names should be nouns or noun phrases.

## Functions and Methods
- Use `snake_case` for function and method names.
- Function and method names should be verbs or verb phrases.

## Constants
- Use `UPPER_SNAKE_CASE` for constants.
- Constants should be defined at the top of the file or in a separate configuration file.

## Types
- Use `PascalCase` for type names (e.g., custom types, enums).
- Type names should be descriptive and concise.

## Modules and Packages
- Use `snake_case` for module and package names.
- Module and package names should be short and meaningful.

## Examples
```python
# Variable
user_name = "John Doe"

# Class
class UserProfile:
    # Method
    def get_user_info(self):
        pass

# Constant
MAX_RETRIES = 5

# Type
class UserType:
    ADMIN = "admin"
    USER = "user"
```
